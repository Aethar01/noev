```noev
fn bell_pair() -> (Bit, Bit) {
    let a = |+>
    let b = |0>
    ctrl a { b.x() }
    (mv a.measure(), mv b.measure())
}

fn main() {
    let d = sample 1000 { bell_pair() }
    print(d)
    print("P(11) = {d.probability((1, 1)):.3}, most likely: {d.most_likely()}")
}
```

```text
$ noev run examples/bell.nv --seed 7
00   526   52.6%
11   474   47.4%
P(11) = 0.474, most likely: 00
```

## Core ideas

<CardGrid>
  <Card title="Linear qubit ownership" icon="approve-check-circle">
    Qubits cannot be copied, aliased, or silently dropped. Moves are written with `mv`, borrows use `ref` and `mut`, and violations fail at compile time with codes `N001` to `N024`.
  </Card>
  <Card title="Automatic circuit extraction" icon="rocket">
    Every function call runs once. Repeated runs use `sample n { … }`, and any run whose measurements only drive conditions, logic, or return values compiles into a single circuit.
  </Card>
  <Card title="Direct quantum notation" icon="pencil">
    Write kets (`|+>`, `|0{b}>`), bras (`<+| mv q`), expectation values (`<ψ| H |ψ>`), controlled blocks (`ctrl`), adjoints (`adj`), and automatic ancilla uncomputation (`with`/`do`).
  </Card>
  <Card title="Native code, export, and interop" icon="laptop">
    Run on `ketrs`, compile natively with Cranelift or LLVM, export OpenQASM 3 or QIR 1.0, target plug-in hardware backends, and embed Noev in Rust, Python, or C/C++.
  </Card>
</CardGrid>
