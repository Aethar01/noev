# Noev

**One language. Two computing paradigms.**

Noev is a statically typed hybrid classical–quantum programming language built around
resource ownership, memory safety, and compiler-managed quantum execution.

Status: pre-development. See [docs/PLAN.md](docs/PLAN.md) for the v0.1 plan.
